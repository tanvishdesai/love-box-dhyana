⚠️ IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════

1. ENVIRONMENT SETUP
   Make sure .env.local has your Convex URL:
   CONVEX_URL=https://your-project.convex.cloud

2. BACKUP DATA
   If you have important existing data, backup first!
   Migration will replace all data.

3. RUN ONCE
   Only need to run migration once to get started.
   Running again will reset data (useful for testing).

4. IMAGES
   Sample uses Unsplash URLs - no setup needed.
   Replace with your own URLs later if needed.
